# Aether

Android app and Kotlin Multiplatform shared library for an offline-first English tutor. Do not add this product to the apex-skills checkout.

- Vocabulary: `GLOSSARY.md`
- Floors: `CONSTRAINTS.md`
- Pins: `DECISIONS.md`
- UI tokens: ApexLedger Precision (`#0F172A`, `#1D4ED8`, `#F8FAFC`, `#334155`, `#64748B`, 48dp targets, vector icons plus text). No emoji.

Run `./gradlew :shared:jvmTest :androidApp:assembleDebug` before calling a change done. `ANDROID_HOME` must point at an SDK with platform 36.
