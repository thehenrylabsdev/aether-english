# Glossary

Learner profile
: The single local record of a learner's name, goals, daily minutes, and optional self-reported level.

CEFR estimate
: A practice label for leveling. It is not a certificate. It is stored only from a self-report or after the learner confirms a placement.

FSRS card
: A review item scheduled with FSRS-5. Ratings are Again, Hard, Good, and Easy.

Fix line
: One tutor correction: original text, replacement, note, and an optional grammar rule id.

Vector document
: A 768-dimensional embedding plus the text it came from. Other lengths are rejected before write.

Runtime
: Either the on-device LiteRT engine or a cloud vendor the learner configured with their own key.

Model download
: A Settings action that resolves a catalogued Hugging Face file, reads its Git LFS oid, downloads the bytes over HTTPS, and keeps the file only when the bytes match that oid.

Thermal band
: The Android thermal status mapped to NONE, LIGHT, MODERATE, SEVERE, CRITICAL, or EMERGENCY. Policy caps hang off the band. The band is not a Celsius reading.

Personal context
: Notes, mistakes, and saved passages retrieved for a tutor turn. Cloud calls omit them unless the learner turns that switch on.

Seed text
: Short original reading, grammar, and exercise copy shipped with the app under the original-project license.

Generated draft
: Text the content pipeline writes on device or through the learner's key, stored with the generated-on-device license.
